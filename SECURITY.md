# Security Policy

This is a student course project. We don't handle user data, payments, or
credentials — but we do work in a shared repo, so:

- **Never commit secrets.** No API keys, tokens, passwords, or private keys.
  If you need one locally, keep it in an untracked `.env` file (gitignored).
- **Found a leaked secret?** Tell the team *immediately* through the team
  chat (don't post the secret itself in an issue). We'll revoke it and purge
  it from history.
- **Found something else?** Open an issue with the `security` label, or
  message a maintainer directly — see the team table in the README.

Supported versions: `main` only. We don't maintain release branches.
